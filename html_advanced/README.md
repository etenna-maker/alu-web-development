# HTML, advanced - SmileSchool

This project builds the SmileSchool landing page from a designer's Figma file, using semantic HTML only. There is no CSS at this stage; the goal is a clean document structure that later projects will style.

## Design

![SmileSchool design](images/design.png)

## Page structure

| Section | Content |
|---------|---------|
| Header | SmileSchool logo and links to Courses, Pricing and Login |
| Banner | "Get schooled" title, tagline, register button and 4 instructors |
| Quote | Student photo, quote, name and role |
| Most popular tutorials | 4 video cards with author and star rating |
| Free membership | 4 benefits and a register button |
| F.A.Q. | 2 rows of 2 questions |
| Footer | Logo, social links and copyright |

## Learning objectives

- Build an HTML page from a wireframe
- Choose the right semantic elements for each part of a page
- Keep heading levels in a logical order
- Write W3C-valid markup
