# CSS, advanced - SmileSchool

This project styles the SmileSchool landing page from a designer's Figma file, using only HTML and CSS. It continues the HTML, advanced project: the same semantic structure, now laid out and styled to match the design.

## Design

![SmileSchool design](images/design.png)

## What's styled

| Section | Styling |
|---------|---------|
| Header | Centered container, logo on the left, white links on the right |
| Banner | Background image, large "Get schooled" title, rounded button with shadow, 4 round instructor photos |
| Quote | Purple background, round photo on the left, quote on the right |
| Videos | White cards with rounded corners, play icon, purple author and duration |
| Membership | Dark background, 4 purple smile icons, purple button |
| F.A.Q. | Centered 2 x 2 grid of questions |
| Footer | Logo on the left, social icons on the right, centered copyright |

## Learning objectives

- Turn a Figma design into CSS
- Lay out sections with Flexbox
- Keep selectors simple and reuse common styles
- Write W3C-valid HTML and CSS
